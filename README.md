# Ивент «Алиса AI × ИТД» — «1 сентября»

Однофайловый веб-ивент ко Дню знаний: **«Первый день в ИТД-школе»**. Приложение целиком
лежит в одном HTML-файле и работает **без бэкенда и без интернета** — все запросы к серверу
подменяет встроенный мок-слой, а WebSocket общей доски — фейковый сокет.

Это фронтенд ивента: экраны, анимации, тексты, задания и вся логика интерфейса.
Боевые данные (задания, баланс, покупки) в этой сборке не используются — их подставляет
мок-сервер, который можно настроить под любую сцену (см. «Настройка состояния»).

## Что в ивенте

| Экран | Что происходит |
|---|---|
| **Онбординг** | Комикс «Первый день в ИТД-школе» — знакомство с ивентом |
| **Задания на сегодня** | Задания «Попроси Алису AI сделать…» (Алгебра, Литература, Биология, История, Английский, География), проверка ответа, награда в мелках |
| **Уже сделано** | Тетрадь с историей засчитанных заданий |
| **Мелки** | Внутренняя валюта: баланс в шапке, счёт идёт за выполненные задания |
| **Школьный магазин** | Товары за мелки: фото на аватарку, аура, кликуха, звонок и другое |
| **Фото на аватарку** | Загрузка картинки, модерация, установка |
| **Доска почёта** | Топ учеников по мелкам за всё время |
| **Общая доска** | Совместное рисование вживую: мел, тряпка, участники онлайн |
| **Сбор макулатуры** | Посты старше трёх месяцев уходят в общий сбор; прогресс до общей цели |

## Что внутри собранного файла

`dist/waste-paper.html` — один самодостаточный файл (~6,7 МБ):

* разметка: пустой `<div id="root">` (приложение монтируется скриптом);
* `mock-runtime` — мок-сервер: подменяет API и WebSocket;
* бандл приложения — минифицированный JS (Preact-подобный рантайм);
* стили — включая вшитые шрифты (Neucha, Bad Script) в `data:`-URI;
* все картинки и иконки — тоже `data:`-URI, внешних запросов нет.

## Структура репозитория

```
dist/waste-paper.html        собранный файл: открывается двойным кликом
src/index.html               разобранная версия: разметка + ссылки на файлы
src/js/mock-runtime.js       мок-сервер с комментариями (API, сокет, данные)
src/js/app.js                бандл приложения (как в сборке)
src/js/app.pretty.js         он же, отформатированный для чтения (в сборку не входит)
src/styles/app.css           стили (как в сборке)
src/styles/app.pretty.css    они же, отформатированные для чтения
scripts/build.py             сборка dist/ из src/
```

## Как запускать

**Собранный файл** — просто открыть в браузере:

```
dist/waste-paper.html
```

**Разобранная версия** — нужен локальный сервер (браузер не даёт грузить ES-модули
с `file://`):

```bash
cd src
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Сборка

```bash
python3 scripts/build.py        # соберёт dist/waste-paper.html из src/
```

Сборщик подставляет содержимое `src/js/*` и `src/styles/*` в разметку
`src/index.html` на место ссылок. Результат **побайтово совпадает** с исходным
собранным файлом — проверить можно так:

```bash
sha256sum dist/waste-paper.html
```

## Настройка состояния (мок-данные)

Всё стартовое состояние задаётся объектом `DEFAULTS` в начале `src/js/mock-runtime.js`
(в собранном файле — тот же объект в первом `<script>`). По умолчанию ивент выглядит
«как в первый день»: 0 мелков, заданий нет, тетрадь и доска пустые.

| Поле | По умолчанию | Варианты / смысл |
|---|---|---|
| `balance` | `0` | мелков на балансе |
| `tasks` | `"empty"` | `empty` · `fresh` · `mixed` · `allDone` · `allSettled` — задания на сегодня |
| `history` | `"empty"` | `empty` · `some` · `many` — записи в тетради «Уже сделано» |
| `verdict` | `"passed"` | `passed` · `rejected` · `failed` · `never` — итог проверки отправленного задания |
| `verdictDelay` | `4` | через сколько секунд придёт проверка |
| `cycleIn` | `0` | через сколько секунд новые задания; `0` — отсчёт не идёт («0 ч 0 мин») |
| `honor` | `"empty"` | `empty` · `top1` · `top3` · `mid` · `out` — доска почёта |
| `shopMode` | `"timer"` | `timer` · `all` — витрина магазина |
| `shopPreset` | `"default"` | `default` · `limited` |
| `purchased` | `"some"` | `some` · `empty` — мои покупки |
| `profile` | `"full"` | `full` · `empty` — чужой профиль |
| `board` | `"empty"` | `empty` · `some` · `busy` — рисунки на общей доске |
| `online` | `0` | сколько человечков «у доски» |
| `chalk` / `cloth` | `2` / `1` | мелки и тряпки в инвентаре |
| `socket` | `"live"` | `live` · `down` — состояние WebSocket |
| `avatar` | `"ready"` | `ready` · `arrives` · `waiting` · `used` · `active` · `pending` · `paused` |
| `waste` | `"zero"` | `zero` · `partial` · `almost` · `done` — сбор макулатуры |
| `wasteTarget` | `0` | общая цель сбора; `0` → «Собрано 0 из 0», `10000` → «0 из 10000» |
| `latency` / `fail` | `250` / `{}` | задержка ответов мок-сервера и режимы ошибок по эндпоинтам |

Задания и их тексты лежат в `TASK_BASE`, состояния — в `TASK_PRESETS`,
генераторы таблиц: `buildTasks()`, `buildHistory()`, `buildHonor()`, `buildBoard()`.

## Заметки

* Данные никуда не отправляются: всё выполняется в браузере, состояние живёт в памяти
  страницы и в `localStorage`.
* Читаемые копии (`*.pretty.*`) — только для чтения кода, в сборке не участвуют.
* Права на ивент, тексты и персонажей принадлежат правообладателю ивента;
  репозиторий публикуется для внутреннего использования.
